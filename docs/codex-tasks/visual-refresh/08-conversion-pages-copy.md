# Task 08: Approve enquiry and commerce copy

Follow `00-shared-rules.md`.

## Objective

Create approval-ready copy for `/enquire`, `/subscribe`, `/cart`, `/checkout`, and `/checkout/confirmation`. Do not change code, prices, products, or payment behaviour.

## Requirements

- Inspect pricing engines, product data, form schemas, validation, tests, VAT wording, payment paths, and current error states.
- Never invent or round prices, timing, entitlement, refund, invoice, activation, or tax claims.
- Clarify the next action and what happens after submission or payment without making unsupported promises.
- Include labels, help text, validation errors, empty states, success states, CTA text, and SEO descriptions.
- Use Political Solutions publicly and the formal legal entity only where required.

## Deliverable

Create `docs/public-site-copy/03-conversion-pages.md`, mapped by route and UI state, with claim/source notes, unresolved questions, and `DRAFT — USER APPROVAL REQUIRED`.

## Verification

- Pass 1: verify every amount, state, field, CTA, and operational promise against code and tests.
- Pass 2: independent end-to-end editorial review of first visit, validation failure, retry, empty cart, checkout, and confirmation language.

Stop for user approval. Do not implement the copy.
