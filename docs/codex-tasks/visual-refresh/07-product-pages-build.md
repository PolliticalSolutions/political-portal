# Task 07: Build the public product pages

Follow `00-shared-rules.md`.

## Prerequisite

`docs/public-site-copy/02-product-pages.md` must have explicit user approval. Otherwise stop and ask.

## Objective

Apply the approved public design system and copy to `/services`, `/constituency-intelligence`, and `/services/election-support`.

## Requirements

- Give each page a distinct job and CTA while keeping one shared visual system.
- Use product-specific visual hierarchy, real verified examples, and restrained image or data treatments. Do not clone the homepage or repeat identical card grids.
- Preserve enquiry parameters, product links, forms, state, structured data, and existing business behaviour.
- Do not edit portal code or use unfinished portal screens as marketing proof.
- Keep page-specific styles public-scoped and reusable only where the reuse is genuine.

## Verification

- Pass 1: existing page tests, CTA/query-parameter checks, structured-data checks, accessibility checks where available, and `npm run build`.
- Pass 2: independent desktop/mobile browser review of all three routes, including keyboard use, headings, copy fidelity, link destinations, overflow, and cross-page differentiation.
