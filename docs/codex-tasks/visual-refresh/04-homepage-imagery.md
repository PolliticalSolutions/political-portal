# Task 04: Produce homepage imagery for approval

Follow `00-shared-rules.md`.

## Objective

Create production-asset candidates for the homepage hero and experience/proof section. Do not edit homepage code or select a winner on the user's behalf.

## Direction

Use the approved hybrid language: light operational surfaces, dossier-like grid discipline, real campaign-work materials, cool navy treatment, and no generic SaaS illustration. Generate one or two candidates for each required asset, not a full-page screenshot.

## Constraints

- Show fictional, unreadable register or count material only. No real personal data.
- No politicians, party logos, flags, rosettes, staged office teams, generic laptop stock imagery, gradients, gold, or green brand accents.
- Use the 2026 palette and leave practical safe areas for responsive text placement.
- Do not fabricate product UI or imply unverified functionality.
- Optimise candidate dimensions and formats for responsive web delivery, but retain a high-quality master.

## Deliverable

- Store labelled previews and technical notes under `docs/design-previews/homepage/`.
- Record prompt, dimensions, format, intended crop, accessibility description, and file size for each candidate.
- Mark every candidate `USER SELECTION REQUIRED`.
- Do not wire candidates into the site.

## Verification

- Pass 1: check resolution, aspect ratio, file integrity, compression, safe areas, and absence of readable personal data.
- Pass 2: independent visual review against the Brand folder, the approved homepage direction, mobile cropping, and the prohibited-content list.

Stop and request the user's selection.
